# Bundled fonts

The dashboard loads no fonts from the internet. These files are the Latin subsets, served by the robosec server at `/static/fonts/`.

| Family | Weights | Licence | Source |
|---|---|---|---|
| Poppins | 400, 500, 600 | SIL Open Font License 1.1 (Indian Type Foundry) | npm package `@fontsource/poppins` |
| IBM Plex Mono | 400, 500 | SIL Open Font License 1.1 (IBM) | npm package `@fontsource/ibm-plex-mono` |

The Signal System (Robo Inc. design system, Draft 0.3) specifies Poppins for text and IBM Plex Mono for readings, labels and addresses.
